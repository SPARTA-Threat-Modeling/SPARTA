# Security Policy

## Supported versions

Security fixes are provided for the current release line (the 2026 line at the time of writing). Older release lines do not receive security updates.

## Reporting a vulnerability

Please do **not** report security vulnerabilities through public GitHub issues.

Instead, report them privately by e-mail to **sparta@cs.kuleuven.be**. Include a description of the issue, steps to reproduce, and the affected version if known.

We will acknowledge your report and keep you informed of progress as we investigate. As a research-driven open-source project we cannot commit to fixed response times, but reports are taken seriously and handled as quickly as we reasonably can. Please give us the opportunity to address the issue before any public disclosure.
